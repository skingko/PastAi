# PastAi Extensions

[English](#english) | [中文](#中文)

## English

Each folder here is one extension for the selection bar, and `index.json` is the catalog the app's market reads from GitHub.

To publish an extension, add a folder with an `extension.json`, run `python3 scripts/build-extension-index.py`, and open a pull request. The format is described in [docs/EXTENSIONS.md](../docs/EXTENSIONS.md).

Brand icons come from [Simple Icons](https://github.com/simple-icons/simple-icons) (CC0). The logos remain trademarks of their owners, and their use here does not imply endorsement.

这里的每个文件夹都是一个浮条组件，`index.json` 是 app 内市场从 GitHub 读取的目录。
